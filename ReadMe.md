# gast-hotel

Verwaltung von Hotelgästen als REST- und GraphQL-Service mit TypeScript, Hono,
Drizzle und PostgreSQL. Das Projekt ist im Aufbau; der Projektplan liegt unter
GitHub Projects.

## Voraussetzungen

- Node.js als Laufzeit
- pnpm als Paketmanager und Task Runner (kein npm, kein Bun)
- Docker für PostgreSQL und Keycloak
